# Support

Use [GitHub Issues](https://github.com/khadinakbarlabs/expo-mobile-app-builder/issues) for installation problems, documentation corrections, and reproducible plugin defects.

Include the host and version, operating system, relevant skill name, expected behavior, actual behavior, and the smallest redacted reproduction. Do not include tokens, signing material, account identifiers, customer data, private source code, or unredacted logs.

For a security issue, use the private process in [SECURITY.md](SECURITY.md) instead of a public issue.
