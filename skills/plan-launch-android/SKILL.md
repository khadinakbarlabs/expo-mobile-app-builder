# Plan Launch (Android)

Pre-launch → Day 0 → 30 days.

## Pre-launch (weeks -6 to -1)

| Weeks out | Action |
|---|---|
| -6 | Set launch date. Internal testing build stable. |
| -5 | Pre-registration campaign live. Influencer outreach. |
| -4 | Press list built (50+ contacts). Demo video shot. |
| -3 | Beta testing track. Recruit 50-100 testers via Reddit. |
| -2 | Production AAB submitted (staged rollout draft). |
| -1 | Final bug fixes. PR embargoed press emails sent. |

## Launch day (Day 0)

| Hour | Action |
|---|---|
| 0:00 | Production rollout starts (1%) |
| 6:00 | Twitter launch thread (founder-led) |
| 9:00 | ProductHunt submission |
| 9:30 | HackerNews Show HN submission |
| 10:00 | Press embargo lifts. Reddit posts to 3-5 niche subs. |
| 12:00 | LinkedIn post |
| 14:00 | Push to 50 personal network DMs (don't ask for upvotes — ask for feedback) |
| 16:00 | TikTok demo video |
| 18:00 | Day-1 metrics review |
| 24:00 | Bump rollout to 5% (if Vitals OK) |

## Day 1-7

- Day 1: respond to ALL reviews + comments
- Day 2: push to 20% rollout if Vitals OK
- Day 3: send "thanks for installing" email if you have email list
- Day 4: collect 5 testimonials from happy users
- Day 5: 50% rollout
- Day 6: TikTok variant 2
- Day 7: Reddit "1 week in, here's what I learned" thread

## Days 7-30

- Push to 100% rollout
- Weekly product update tweets
- Reach out to 10 podcasts/newsletters
- ASA-equivalent: Apple Search Ads = Google App Campaigns. Test with $20-50/day budget.
- Run Listing Experiments (icon, screenshots, copy)

## Launch metrics targets (indie reality)

- Day 1: 100-500 installs
- Day 7: 1k-3k installs
- Day 30: 5k-15k installs
- Conversion to paid: 2-5%

## Common mistakes
- Launching before Internal Testing track is stable
- Posting to subreddits in self-promo manner = downvote
- Not responding to first reviews = bad signal to Play algorithm
- Stopping marketing 2 weeks after launch = momentum dies
