# Pre-Registration Campaign (Play)

Build install pipeline 3-6 weeks before launch. Auto-installs when live.

## How it works

1. You enable pre-registration in Play Console
2. Users opt-in via Play Store listing (still pre-launch)
3. App downloads automatically when you release
4. Users get a launch notification

Conversion: 60-80% of pre-registers install when released.

## When to use

- Game launches (highest ROI)
- Highly-anticipated apps
- Apps with influencer/community backing
- Apps with marketing budget (>$5k) for pre-launch
- 3-6 weeks of runway

When NOT to
- Solo indie with no audience
- Hyper-niche app
- Launch within 2 weeks (need 3+ weeks for momentum)

## Setup

Play Console → Releases → Pre-registration → Create.

1. Upload assets (screenshots, video, description)
2. Set release date (estimated, can change)
3. Pre-register goes live for opt-ins
4. Optional: reward for pre-registers (exclusive content, badges)

## Marketing for pre-registration

- Social media (Twitter, TikTok, Reddit) directing to Play
- Pre-launch website with Play badge
- Influencer outreach (gaming/niche YouTubers)
- Email list building (subscribe for launch notification)
- Press outreach for game/lifestyle launches

## Launch day

Day 0:
- Pre-registers auto-install
- Send Push notification (Play handles this)
- Social media announcement
- Press release
- ProductHunt / HackerNews submission

## Common gotchas
- Pre-register conversion: 60-80%; plan for ~70%
- Quality assets matter more pre-launch (no installs to prove worth)
- Delaying launch = pre-registers lose interest
- 90-day cap on pre-registration campaign

## Combine with Internal Testing
Pre-registration LIVE listing + Internal testing track for fast iteration.
