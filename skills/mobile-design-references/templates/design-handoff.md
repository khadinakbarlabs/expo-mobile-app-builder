## Assets

Owned/licensed asset path, author/source, usage license, attribution, theme variant, crop, accessibility description, and unresolved approvals.

## Motion and adaptation

Reduced motion, keyboard/insets, back behavior, large type, RTL, offline/permission behavior, and platform-specific controls.

## Development and QA

Implementation owner, available measurements/exports, unresolved decisions, runtime comparison plan, device matrix, test fixtures, and expected proof. Distinguish design approval from runtime QA.
