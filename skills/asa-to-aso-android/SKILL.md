# Google App Campaigns → ASO Loop

Run paid Google App Campaigns, mine winning keywords for organic ASO.

## What's Google App Campaigns
Google's Universal App Campaign — runs ads across Search, YouTube, Play, Display. Google AI optimizes for installs or in-app actions.

## Why it informs ASO

App Campaigns reports which user queries → clicks → installs. The high-converting queries = your organic ASO targets.

## Setup

1. Google Ads → Create campaign → App promotion
2. Set conversion goal: installs OR in-app event (e.g., signup, paywall)
3. Budget: start $20-50/day
4. Add 4-5 text variants (headlines, descriptions)
5. Add images + video (Google rotates)

## Track winning queries

Google Ads → Reports → Search Terms (for App Campaigns).

You'll see which queries trigger your ads + which convert. The high-converters (CTR + install rate) = your organic gold.

## Apply to ASO

1. Take top 10 converting queries
2. Add as new keywords to Play title/short description
3. Update long description to weave them in
4. Within 4-6 weeks, organic rankings shift

## Apple Search Ads parallel

If running iOS too, ASA Search Tab campaigns give same data for iOS keywords. Add to your data set.

## Budget reality

- $50/day for 30 days = $1,500 budget
- ~500-1,500 installs (varies by category)
- ~10-30 high-converting query insights → 3-5 organic ASO gold keywords
- ROI: ASO lift > paid ad spend within 90 days

## When NOT to
- App not yet validated (don't pour money into bad PMF)
- <$2k monthly burn (better spent on product)
- No conversion tracking (waste of insights)
