# Position Pitch

Apply Hormozi's Value Equation to an iOS app. Output tagline, App Store subtitle, paywall headline, onboarding promise.

## Value Equation
`Value = (Dream Outcome × Perceived Likelihood) / (Time Delay × Effort & Sacrifice)`

## Workflow
1. Dream Outcome in one sentence (aspirational, specific, emotional — NOT a feature list)
2. List 3 Perceived-Likelihood proofs (numbers, names, credentials, screenshots, testimonials, Apple Foundation Models on-device)
3. Pin Time-to-Value ("First headshot in 60 minutes")
4. Pin Effort ("Take one photo. We do the rest.")
5. Generate assets:

```
APP NAME: [3-15 chars]
TAGLINE (subtitle, 30): [Dream Outcome compressed]
ONE-LINER (12-20 words): [full value prop]
PAYWALL HEADLINE: [Dream × Likelihood]
PAYWALL SUBHEAD: [proof points]
ONBOARDING SCREEN 1 PROMISE: [Time-to-Value]
ONBOARDING SCREEN 2 PROMISE: [Effort minimization]
ONBOARDING SCREEN 3 PROMISE: [next dream]
APP STORE DESCRIPTION OPENING (first 3 lines): [hook + dream + proof]
```

## Compliance check
Before shipping: run `pre-submission-audit` — no "best", "#1", "fastest" claims you can't substantiate (2.3.1 reject).
