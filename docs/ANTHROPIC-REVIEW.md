## Behavior and data disclosures for review

The Claude bundle includes instructions, templates, readable local helpers and static artwork. It has **no declared MCP server, connector, startup hook, analytics collector, hosted-service source or signing credentials**. Local helpers inspect files and print catalogs, plans or preflight results. The AI host accesses files only under its own controls and the user's scope.

Skills can guide user-authorized network/tool actions: Apify collection, package installation, provider APIs, builds, analytics setup and store/growth operations in the consuming app. Those operations may send project data or incur provider costs; actual destinations/accounts depend on the user's project choices. They are not automatic plugin-install behavior. Provider credentials belong in the chosen provider's secure local/account configuration, not this public package. The separate hosted planning adapter is not connected by the Claude manifest.

The owner should review the native package and actual intended workflow behavior before completing the portal's data, retention, age-audience and policy questions. Those answers, publisher identity verification, compliance-contact email and legal attestations are not inferred or pre-approved by this document.
